Lưu vào file

Ghi toàn bộ dữ liệu hiện tại vào chính file .html này. Lần sau mở file là thấy dữ liệu mới nhất. Phím tắt: Ctrl + S.

Sao lưu dữ liệu

Tải toàn bộ sản phẩm, hình ảnh và phiếu nhập xuất về một file .json để cất giữ riêng.

Khôi phục dữ liệu

Chọn file .json đã sao lưu trước đó. Dữ liệu hiện tại sẽ được thay bằng dữ liệu trong file.

Nạp lại dữ liệu mẫu

Xóa dữ liệu hiện tại, nạp 12 sản phẩm kèm ảnh minh họa và 12 tháng giao dịch mẫu để trình diễn.

Bắt đầu kho trống

Xóa sạch sản phẩm và giao dịch để nhập dữ liệu thật của mình từ đầu.
